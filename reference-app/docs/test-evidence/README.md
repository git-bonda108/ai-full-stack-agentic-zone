# Test evidence

Generated by `bash scripts/run_quality_gates.sh` (and by CI). This folder is the
"expected test evidence" a reviewer, auditor or release manager looks at.

| File | Produced by | What it proves |
|---|---|---|
| `eval-report.md` / `eval-report.json` | `python -m evals.run_evals` | AI behaviour: each golden invoice gets the expected decision and reason codes (regression gate) |
| `junit.xml` | `pytest --junitxml` | Every unit + integration test result (CI test tab) — regenerated, git-ignored |
| `coverage.xml`, `htmlcov/` | `pytest --cov` | Line coverage; `backend/app/domain` must be ≥ 90 % — regenerated, git-ignored |

Committed snapshot: the eval report from the last green run. Re-run the gates
before a release and attach the folder to the release / Jira story as evidence.
